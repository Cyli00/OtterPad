# 落进生产界面

## 范围

只迁移获准的内容子树。应用主导航、设置分类导航、移动底部导航、窗口标题栏与按钮、阅读器顶部／底部工具栏、侧栏开合行为保持原样，也不通过全局 Theme 或 IconTheme 连带改动它们。

复用已有的业务状态、路由和浮层宿主，不新造浮层路由：返回键、Esc、点击外部关闭和焦点恢复语义沿用原样。平台决定交互宿主，可用宽度决定布局。

## 要保留的东西

- 用户可见文本进 ARB；Widget 走 `context.l10n`，服务层沿用项目上下文；Prompt、正则、技术标识符不进 i18n。
- 保留业务值、默认值、校验、防抖、焦点、滚动位置、异步状态与保存频率；获取模型保留加载／结果／重试，旧请求不能覆盖新配置。
- 图标用现有 Material Symbols，专家／快速／图像角色分别为 `Symbols.psychology`、`Symbols.bolt`、`Symbols.draw`，配文字名称、不靠颜色识别。生产已引用的是 `*_rounded` 变体；不为演示、示例或迁移新增 Symbols 引用，确实需要新字形时先与用户确认字形与包体积影响。
- 动效使用项目 `animation_constants.dart`；示例语义时长为快 180ms、标准 240ms、easeOutCubic。减少动态效果时去掉装饰运动；不以尺寸动画驱动 PDF、WebView 或整窗逐帧重排。
- 触觉经 Haptics；列表用稳定业务 key；禁用、错误、值和选中状态可读屏，异步互斥操作不可重复提交。
- 演示不得读取真实凭据，不把输入值写日志或截图；生产安全存储保持原路径。

## 主题与阅读

应用浮层继承应用主题，阅读内容浮层继承阅读区主题。Flutter 文本样例可换色，PDF 固定版面样例与插图保持原色。颜色变化走原位主题更新，不重建文档、不重新请求翻译；原生 WebView 底色、HTML 首帧与 Flutter 容器要一起验证以避免白闪。阅读设置值与枚举序号的保留要求见 [tokens.md](tokens.md#明暗与阅读纸面)。

示例只验证换肤与组合，不代表已接入真实 PDF／WebView 或完成生产主题迁移。
