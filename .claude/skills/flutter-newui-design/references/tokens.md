# 颜色、字体与密度

量化 Token 的代码真源是 [paper_theme.dart](../examples/ai_settings/lib/paper_theme.dart)；这里是规范侧的口径。

## 颜色：只有石墨明暗，不提供强调色选择

页面、文字、表单和操作统一采用中性纸白／石墨。移除蓝、紫、绿等应用强调色入口，不让种子色或系统壁纸重新染色新内容区。图表、原稿、品牌资产保留自身颜色；错误仍使用独立语义色，并有图标／文案，不能只靠颜色传达状态。

| 语义 Token | 浅色 | 深色 |
|---|---|---|
| 页面 surface | `#F2F0EC` | `#1C1B19` |
| 卡片／输入 surfaceContainerLow | `#F9F8F5` | `#252420` |
| 高层／提示 surfaceContainerHighest | `#EDEAE4` | `#302E29` |
| 正文 onSurface | `#1F1E1B` | `#F2F0E9` |
| 次要文字 onSurfaceVariant | `#66635B` | `#B8B3A8` |
| 交互石墨 primary | `#55524B` | `#D5CEBD` |
| 主按钮文字 onPrimary | `#FBFAF7` | `#25231F` |
| 常规边框 outlineVariant | `#E3E0DA` | `#48453E` |
| 强边界 outline | `#8A867E` | `#948D80` |
| 选中 selected | `#DFDBD4` | `#454137` |
| Hover 表面 | `#EBE8E2` | `#39362F` |
| 错误 error | `#A4362F` | `#F2A69D` |

状态应用：常规边框 1；焦点边框 2，使用 primary。分段交互叠色为 hover 6%、pressed 12%、focused 16%；禁用前景为正文 38%。静态边框可以轻，正文与有效说明文字不低于 4.5:1。[对比度标准](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

## 明暗与阅读纸面

应用提供自动／浅色／深色。阅读纸面提供跟随应用与固定白纸、米纸、淡绿、夜间、纯黑，固定选择独立于应用明暗。石墨交互色按实际纸面亮度解析，避免深色应用上的白纸链接过亮。

生产迁移时保留已有阅读设置值与枚举序号，不把旧“白纸”静默改成“跟随应用”。做这些组合验证时读[外观页与阅读配色](../examples/ai_settings/lib/appearance_demo.dart)、[appearance_palette.dart](../examples/ai_settings/lib/appearance_palette.dart) 与[验收](verification.md)。

## 字体与密度

默认使用系统 `sans-serif`，标题、正文、控件保持同一字体体系。`serif` 是“显示设置 → 界面字体”的选项，默认不启用；取消不写回，保存换字体时保留输入草稿。独立阅读字体偏好与 PDF 原稿字体不被界面字体覆盖。

不新增字体包、不恢复 `fonts:`、不下载或制作字体子集。原生宿主使用已安装系统字体并验证 CJK 回退；本机 Web 预览的字体桥接见[验收](verification.md)。

下表为 Flutter 逻辑单位，字号在系统文字缩放前定义：

| 项目 | 数值 |
|---|---|
| 页面标题 | 桌面 32 / 移动 24，600 字重，1.25 行高 |
| 分组标题 | 20，600，1.4 行高 |
| 子分组／收藏夹标题 | 16，600，1.5 行高 |
| 字段标题 | 14，600，1.5 行高 |
| 正文／输入／按钮 | 14，400，1.5 行高 |
| 说明／元信息 | 12，400，1.5 行高 |
| 页面左右内边距 | 桌面 32 / 移动 16 |
| 分组间距 | 24 |
| 卡片内边距 | 16 |
| 同组控件间距 | 12 |
| 分组标题到卡片 | 8 |
| 字段外置标题到控件 | 4 |
| 单行输入内边距 | 水平 12 / 垂直 10 |
| 按钮内边距 | 次操作 12×8 / 主操作 16×8 |
| 标准单行输入 | 桌面至少 44 / Android 至少 48 / iOS 至少 44 |
| 按钮与图标命中区 | 桌面至少 40 / Android 48 / iOS 44 |

紧凑感来自字号和留白，不能缩小命中区、压制系统文字缩放或固定高度裁掉多行内容。常规图标 20、帮助 18、模型角色 22，线性字重 350、fill 0；普通图标背景透明。阅读长文可以采用 16 的正文和约 1.85 行高，不能反过来把所有设置控件放大为阅读字号。
