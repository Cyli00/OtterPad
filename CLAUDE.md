## UI Design Rules (Strict MD3 Compliance)

**Check Items:**

- **Tokens**: USE MD3 Design Tokens exclusively. ZERO hardcoded colors, sizes, or spacing.
- **Theme**: IMPLEMENT correct dark/light adaptation via dynamic tonal palettes.
- **Color Roles**: APPLY Primary, Secondary, Tertiary, and Error roles semantically.
- **On-Colors**: ENFORCE "On-Colors" strictly (e.g., On-Primary text on Primary containers).
- **Contrast**: GUARANTEE foreground/background contrast meets A11y standards.
- **Grid**: ALIGN all elements firmly to the 8dp grid (4dp for tight spaces).
- **Breakpoints**: ADAPT responsive layouts to valid Window Size Classes (Compact to Extra-large).
- **Typography**: APPLY only the 5 MD3 type roles (Display, Headline, Title, Body, Label). Lock line height and tracking to tokens.
- **Elevation**: INDICATE elevation classes (0-5) using BOTH Shadows and Surface Tints.
- **States**: COMMUNICATE Interaction States (Hover, Focus, Pressed) via State Layers. Use multiple visual cues.
- **Motion**: SYNC duration and easing curves to MD3 (Emphasized transitions, Standard feedback).
- **Icons**: ENSURE unambiguous meaning. Use variable styles.
- **Touch**: STRCTLY ENFORCE a minimum 48x48 dp touch area for all interactive components.
- **A11y Aids**: PROVIDE text labels or tooltips for abstract icons and guarantee complete screen reader support.
