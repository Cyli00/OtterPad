# 双语标注关联蒙版：方案归档

日期：2026-09-17。状态：已撤除，不是待启用的隐藏功能。

## 决策与边界

用户反馈 PDF 和 WebView 的双语标注映射仍有较多问题，决定先移除标记后自动出现在另一语言上的关联蒙版，保留思路供以后评估。

本次移除的是原文 ↔ 译文之间的自动标注投影，不是全文翻译、双语排版，也不是用户自己选中文字后的普通高亮。

保留既有高亮、颜色、笔记、标注分组、数据库记录和锚点格式。同语言仍可在 PDF 与 WebView 中按段落身份恢复选中文字；隐藏标注所属语言时不绘制，重新显示后恢复。不清空书库，不重新 OCR，不删除译文缓存，不做数据库迁移。

## 原方案

共享标注用 `ReaderAnchor` 保存若干范围，每段包含：

- `paragraphId`：`ReaderDocumentIndex` 建立的段落身份。
- `language`：原文使用 `source`，译文使用目标语言标识。
- `revision`、UTF-16 `start/end`：标注时的文本版本和字符范围。
- `quote/prefix/suffix`：文本变化后的保守重定位依据。

同语言用精确范围；跨语言没有可靠的逐词对应，因此只按同一段落身份显示整段淡色底，表达“这段在另一种语言中有标注”，而不是表示译文中的每个字都被选中。

### PDF 路径

`ReaderPdfAnnotationGeometry` 将锚点与页面排版块匹配。同语言由字符框合并出行框；跨语言曾生成整段关联行框和左缘边标。行框优先取排版行，其次取字符框，缺少映射时退回段落框。

`ReaderLayoutPage` 的绘制层曾用更淡的同色底绘制关联行框，用主题色绘制边标。命中测试支持关联行框、边标及段落内的后备查找，使另一侧可打开原标注工具栏。

### WebView 路径

HTML 通过 `data-paragraph-id` / `data-language` 标记正文与译文。`reader_anchors.js` 将规范文本绑定到 DOM 字符位置，`reader.js` 将 Range 转成 SVG 行级高亮，并在重排、公式渲染和译文更新后重新定位。

跨语言分支最初只返回首字符 Range，因此出现“译文整段有高亮，原文只在 Recent 的 R 附近有小块”的现象。随后曾改为整段 Range，并携带关联标记，使用 0.12 透明度区别于普通高亮的 0.3；同一标注的重复关联段落做去重。该局部修复通过了浏览器回归，但不代表完整双语映射已达到产品要求。

## 暴露的问题与限制

- 段落身份相同不等于可以逐词对齐；拆句、合句和翻译重排使精确投影缺少依据。
- OCR 跨栏、跨页合并和错误分类会改变文本边界；PDF 几何与 WebView 的线性 DOM 并不天然一致。
- WebView 的文本规范化、公式、嵌套节点与增量译文更新增加定位复杂度。首字符问题已定位，但用户仍反馈覆盖缺失、不全及其他问题，不能视为已经全面解决。
- 整段淡底容易与实际选区混淆；另一侧的整段点击热区也可能让普通正文看起来具有不可见的标注交互。
- 小型回归只能验证选定路径，不能替代真实复杂文献、多语言与桌面交互验收。

## 本次代码收尾

- PDF：删除跨语言标记生成、关联行框后备推导、边标、专用透明度和主题色依赖；删除关联点击与段落后备命中。只保留实际高亮行框的命中及其正常容差。
- WebView：锚点恢复时跳过语言不同的绑定；删除关联 Range 元数据和 SVG 专用样式。增量更新与模式切换不得重新生成跨语言蒙版。
- 更新 WebView 资源版本，使旧页面缓存不会继续运行原关联脚本。
- 更新现行阅读器文档，回归改为验证“不跨语言绘制或命中，同语言标注及笔记仍保留”。

## 将来若重新评估

不直接恢复整段自动投影。先明确产品是否需要单纯的“另一语言存在笔记”提示，还是可靠的逐句对应；两者应是不同能力。若需要精确映射，必须先建立可验证的对齐数据与失配时的明确行为，覆盖重复段落、拆合句、公式、跨栏跨页、增量翻译和版本变化。未获得新的需求授权前，不恢复这套关联蒙版。

## 撤除验证与遗留项

PDF 双向语言隔离与点击范围测试、WebView 锚点及实际 SVG 浏览器测试、增量译文/模式切换回归、真实 PDF 原文与译文拖选回归均通过；改动文件静态检查通过。没有在桌面应用中进行人工鼠标验收。

额外运行的扫描件选区测试 `扫描件文字层可按字符构造共享锚点` 失败：期待 `paragraph`，实际返回 `paragrap`。该测试进入的 `anchorForSelection` 未改动，其依赖的 `mergeLineRects` 与 HEAD 完全一致；此次未扩大范围修复选区尾字问题，也不以关联蒙版撤除的通过结果掩盖这项失败。
