# 并发、取消和导出改进

本轮对应对照报告的第 3、4 项，日期 2026-09-11。

## 使用上有什么变化

- 同时翻译多篇文献，全文翻译合计最多发送 8 个请求，其余排队。原有文献任务队列上限 5 和 PDF 串行锁继续负责各自资源；没有把所有工作塞进同一条队列。
- 取消全文翻译会中断等待中的请求、网络请求和重试等待，已完成的段落仍保存。重新翻译会先等待上一轮保存结束，再清缓存和重新开始，避免旧任务覆盖新任务。
- 翻译进度在任务销毁时注销，后续异步回调不再更新已销毁的进度对象。不同语言和图题翻译的文件写入也按文献串行处理，避免相互覆盖。
- PaddleOCR 异步提取的进度查询、结果下载也传递取消信号；取消不再被当作查询失败而触发回退。结果下载或保存失败，不再显示为完成。中断本机请求不代表已经撤销服务商服务器上的任务或计费。
- 缩略图等待超时后，真实渲染结束前仍保持去重；释放图片和 PDF 后才交出串行锁。原生渲染本身不是强制终止。

## 如何导出

在文献卡片右键菜单（手机长按）选择“导出文献”，或多选后点击导出按钮。

- “笔记和标注（Markdown）”：导出题录、选中文字、对应笔记和时间。跨段标注合并展示，共同笔记不重复。没有笔记也会保留题录，并说明为空。
- “参考文献（BibTeX）”：导出标题、作者、现有出版来源、年份、DOI 和关键词，保留中文并转义特殊字符。引用键来自稳定文献 ID。
- 桌面选择保存位置；移动端调用系统分享。多选栏超出窄屏宽度时横向滚动。

现有 Document 没有可靠的出版类型、卷期页码，且 journal 字段可能存出版社或书名。因此暂时输出 `@misc`，出版来源写入 `howpublished`，不猜成期刊论文。标注没有准确页码，本轮也不编造页码。导出包含 OtterPad 已保存的标注笔记，不包含尚未导入的 Zotero 标注。
