# 桌面 PDF 阅读

顶部恢复为原来的 PDF／Markdown 切换。解析后两种视图共用阅读工具栏、标注和全文译文。PDF 原文和译文都可直接拖选，松开鼠标唤起高亮、复制、笔记、划词翻译和问 AI；不再提供独立版式模式或段落展开面板。单击正文中已有的标注即可打开同一条标注的工具栏；译文/原文一侧的跨语言关联提示（段落淡底色 + 左缘边标）同样可单击。

宽屏下 PDF 提供原文／双语／译文三态；双语把同一原始页排两次——左侧原文、右侧译文——共用同一个 `PdfViewer`，滚动、缩放和页面几何天然同步。窄窗只保留原文与译文两态：双语投影为译文，不改写保存的翻译模式，也不重新翻译。展示层替换只换文字层，原页面、分栏、图表和独立公式仍来自同一份原始页面位图；译文使用实际字体与行内公式测量字号，只借用同栏内的安全留白，下一段、图表、公式和页眉页脚作为边界。

## 共享数据

`ReaderDocumentIndex` 为 PaddleOCR 和 MinerU 统一段落身份及 Markdown 范围。翻译仍复用文档级 provider、任务队列和 `translations.json`，切换视图、切换翻译模式都不重新请求。标注仍保存在 Drift 的同一条记录，通过段落、语言、版本及 UTF-16 范围定位；同语言精确恢复字词范围，跨语言只在对应段落上给关联提示并允许打开同一条标注。

原生 PDF 字符在已知段落区域内与 OCR 文本对齐，处理换行断词、字体连字、上标和少量识别差异。复制按钮、复制快捷键、问 AI 引用和划词翻译统一使用对应的 OCR 段落选区；跨段保留段落间隔，没有可靠 OCR 时仅修复视觉换行。划词翻译同时取得完整段落，继续使用流式翻译与选区强调 UI。低相似度不强行生成精确锚点。扫描件使用 OCR 框生成透明的可选文字层。

## 标注与选区

- 同一语言的标注按行框合并后绘制：轻透明度（0.3）、轻圆角，跨栏、跨段和不连续片段不会被拼成一整块；公式占位符的重复字框只画一次。
- 绘制顺序固定为「译文擦除 → 译文内容 → 持久标注 → 搜索/当前选区」，译文区的白底已盖住 pdfrx 画在页面画布上的原生选区，自绘选区只补在这层之上，不会重复加深。
- 跨语言（原文 ↔ 译文）不伪造逐字对应：在对应段落上叠一层更淡的同色底，并在段落左缘保留 ColorScheme 边标；点击段落即可打开这条标注。
- 拖动选择由 `ReaderPdfInteraction` 合并到帧末采样：最多一个异步读取在途，相同范围不通知绘制层，松开后解析一次规范引用并弹工具栏。标注点击共用几何命中，不再重复等待插件单击回调或加载链接。
- 选区、锚点和悬浮工具栏在鼠标按下、取消、清空选区、切换翻译模式和页面替换时一起失效，过期的异步结果不再弹菜单。

## OCR 与排版边界

- 翻译范围：正文、摘要、大标题、小标题、独立 figure/chart/table title。图表内部文字、表格单元格、HTML 表格、`vision_footer` 和视觉脚注不进入全文翻译。
- PaddleOCR 的同组文本可能将完整段落放在首框，续栏只保留空框。读取时按同页 `group_id` 恢复多个文字区域，按面积分配译文容量；保留段落内容和缓存身份，旧解析与已有译文直接生效。
- MinerU 的合并段落可能跨栏或跨页。结构模型保留行组区域与 `cross_page` 标记；多个区域共享一个段落 ID 和翻译哈希，译文沿原区域分配，公式与 UTF-16 代理对不会被切断。
- 新提取结果持久化 `text_regions`。旧 MinerU 缓存没有行区域元数据时使用原 bbox；遇到跨栏／跨页合并段落，需要重新解析一次以取得这些区域信息，已有译文仍按原文哈希复用。
- 缺少可信坐标且不能从 PDF 唯一定位的段落继续保留原页显示；完整译文仍可在 Markdown 查看。
- 原 PDF 文件不被改写。PDF 页面代理只提供当前可见的文字层，绘制层叠加译文与标注。文字层按排版后的实际可见行写入，行末换行只属于显示层，复制文本与翻译哈希不受影响。

## 桌面自适应与页号

- 外观面板不再提供横向／纵向翻页：桌面正文固定连续上下滚动，移动端继续使用各自的翻页设置（同一份持久值互不干扰）。
- 并排阈值取显示器逻辑宽度的 62%（限制 1000–1440 px）与 `字号 × 60 + 64 px` 中的较大值，以扣除侧栏和左右边距后的实际可用宽度判断；退出阈值低 64 px，避免临界宽度反复切换。
- PDF 显示槽位与源页分离：`sourcePageNumber` 是 OCR 区域筛选、`structurePage` 查找、`pdf-page:N` 后备锚点和阅读进度的唯一依据，`pageNumber` 只是显示槽位。双语时源页 N 产生 `[2N-1, 2N]` 两个槽位，界面总页数与历史进度仍按源页计数（`slotForSourcePage` / `sourcePageForSlot`）。
- 展示层（原文/译文/双语）切换后按源页恢复阅读位置，并清空选区、重绑搜索；同一源页的两个槽位不会各上报一次进度。

## HTML 双语与模块职责

提取结果固定连续滚动。宽屏双语按同一个 OCR 段落生成一行：左原文、右译文，较长一侧决定行高；窄窗恢复上下对照。标题、列表、引用保留 Markdown 语义，图片和表格只显示一次。双语图题在同一个图下配对。非双语正文以随字号变化的舒适行长居中。

`ReaderMarkdownPresentation` 仅在正文或索引变化时按原文偏移标记段落身份。HTML 构建阶段消费标记，生成稳定的原文与译文容器及 `data-paragraph-id` / `data-language`；图题按身份或唯一对应关系绑定，图片和表格不复制。标注优先按明确身份绑定，旧结构才回退文本查找。布局宽窄切换只更新 CSS，保留当前段落的位置。

逐段译文继续实时提交。译文 HTML 按原文哈希缓存，未变的段落复用同一份展示数据；`reader_update_plan.dart` 只发送发生变化的段落，`reader_translations.js` 按帧合并更新对应译文容器。切换原文／双语／译文只调整容器可见性，原文、图片、表格和已有公式节点保持复用，不重新加载整页。新的译文公式使用现有 KaTeX 配置渲染，标注在更新后按段落身份重新绑定。

鼠标拖选期间暂缓提交；松开后，包含当前选区的段落继续等待选区清除，其余段落正常更新。标注工具栏或搜索打开时暂缓布局更新，关闭后提交最新结果，避免工具栏位置或搜索结果在操作中变化。每批更新前后测量当前选区或视口段落的位置，用滚动补偿维持阅读位置。隐藏的原文与译文不参与搜索和锚点匹配。

首次打开或正文发生变化仍使用 `ReaderHtmlCache` 串行生成完整页面，并跳过尚未开始生成的过期版本。页面就绪后补交加载期间收到的最新译文，避免遗漏异步结果。

PDF 交互由 `coordinators/reader_pdf_interaction.dart` 统一持有，主页面只处理标注、笔记、翻译和 AI 业务回调。页面绘制分为两个独立 RepaintBoundary：静态译文及标注、实时选择及搜索；搜索和选区按整页译文区域一次裁切，不再对每个段落重复绘制。

`ReaderPdfDocumentRef` 按源页和源/译类型缓存页面内容；两侧共享同一源页的原生文字，显示槽位变化只换代理并转移排版资源归属。只在该页内容、样式或 OCR 结构变化时重新排版。段落按源页预索引，字符矩形每页只转换一次。续栏可见行范围始终使用完整段落偏移，标注几何遍历该段落在当前页的全部区域。

## 实现参考

借鉴 retain-pdf 的受保护区域边界、字号测量和文字层分离，以及 Agentero 的原生 PDF 选择与就地译文。使用现有 Flutter／pdfrx／flutter_math_fork 实现，没有增加渲染服务或外部运行时。

## 验证

```bash
flutter analyze --no-pub
node --check assets/reader/reader.js
node --check assets/reader/reader_anchors.js
node --check assets/reader/reader_translations.js
flutter test test/pages/reader/reader_layout_test.dart test/services/reader_document_index_test.dart test/providers/reader_shared_data_test.dart
node test/reader_anchor_dom_test.cjs
flutter test test/pages/reader/reader_pdf_cache_test.dart test/pages/reader/widgets/webview_reader_html_test.dart --no-pub
```

增量翻译回归运行 `test/pages/reader/widgets/reader_incremental_translation_test.dart`。若设置 `READER_INCREMENTAL_FIXTURE` 为 `build/reader-incremental-fixture.json` 的绝对路径，该测试会输出实际生成的页面与增量数据；随后运行 `node test/reader_translation_dom_test.cjs`，检查滚动补偿、拖选、工具栏暂停、公式、模式切换和受保护节点复用。

`reader_layout_test.dart` 覆盖真实 PDF 的原文和中文鼠标拖选、跨段锚点、旋转、扫描件、长中文、行内公式及受保护区域。现有 MinerU 论文 fixture 同时验证跨栏跨页段落的字符覆盖率。设置 `READER_PDF_VISUAL_OUTPUT` 为 PNG 路径可输出原页与部分译文的排版核对图；测试样张使用本地示例翻译，不调用外部接口。

人工验收用一篇 PaddleOCR 和一篇 MinerU 文档：原文拖选→高亮→单击段落改色/笔记；译文跨行拖选复制无断行；宽屏切换双语后左右分别是同一源页的原文与译文，页号、目录、搜索、进度仍按源页计数；缩窄窗口恢复译文两态后再放宽能回到双语且位置不漂移。

本次重点验收：HTML 宽窄双语与重复段落标注；PDF 连续短距离拖选、快速重复单击标注、切换源/译/双语后再选字。静态分析和定点回归不能替代桌面鼠标手感的实际验收。
