2视觉设计提案（总体风格不变，桌面端做差异化）

2.1 全局微调（保持现有 Material You 简洁风格，只做"收齐"）

  • 抽 SettingGroup 公共组件：7 份复制收敛为 1 份，内置 Material(transparency) 祖先（本次修复的断言问题一并根治）。
  • 阴影分层进规范：在 flutter-design §1 补一张表——
    悬浮层级: Card<浮层工具条<BottomSheet<Dialog blur: 10 16 20 24 y: 4 8 10 12
    桌面端 hover 时 Card 阴影 blur 10→16 做"抬升"暗示。
  • 动画常量补档：kAnimPulse（循环 1200ms）、kAnimEmphasis（500ms，大强调），收编 translation_popup / spotlight 硬编码。
  • 分隔线收敛：全局分隔线统一 outlineVariant.withAlpha(70~80) + 缩进规则进规范（当前有的页 indent 20、有的 80）。

3动画体系提案（重点：从"曲线补间"升级为"物理弹簧"）

3.1 现状诊断

  • 规范良好：kAnimFast/kAnim/kAnimSlow(180/240/320) + easeOutCubic，路由转场用官方 animations 包。
  • 短板：
    • 全平台 0 个弹簧动画（除手写 _SpringDismissible）——按压、勾选、面板开合都是定长曲线，手感"硬"。
    • 无交错入场：列表/网格整体闪现。
    • 无容器变换：书库卡片 → 阅读器是 Scale+Fade 自绘过渡，封面没有空间连续性。
    • flutter_animate 全项目只用 4 处，价值没吃出来。

3.2 包选型（均已核 pub.dev 最新版，2026-02）

包最新版角色建议
animations（官方）2.1.2 → 3.0.0（2026-08 发布） FadeThrough / SharedAxis 路由转场，继续服役 升级 纯维护性升级（迁 material_ui；要求 Flutter ≥3.44，本机 3.44.6 满足）
motor1.1.0（2025-12） 弹簧物理引擎（springster 作者的继任包）：Motion.spring 驱动的按压回弹、悬停抬升、面板开合、数值补间 引入 替代手写 SpringController 的散点实现
heroine0.7.2（2026-03） 弹簧化 Hero 转场（封面卡 → 阅读器头图连续形变） 可选 0.x 版本，API 可能动荡；放在 P3 单独评估
flutter_animate4.5.2（现有） 声明式入场/微动效 保留收敛 不改路由级用法的禁令不动，收成统一 preset（如 Fx.fadeSlideIn）避免各处乱调

不引入 flutter_staggered_animations（停更多年）、不引入 Rive/Lottie（本应用无品牌化动画需求）。交错入场自写 ~30 行 helper 足够。

3.3 动效规范 2.0（写入 flutter-design §1.5 的内容草案）

场景参数
按压微交互（卡片/按钮按下→抬起）motor spring：scale 1→0.96→1；stiffness 400 / damping 22（欠阻尼微回弹），可中断
选中态勾选 / 图标盒spring scale 0.8→1 + 不透明度，200ms 内完成
列表交错入场首屏每项延迟 30ms，上限 8 项；fade + slideY(12px→0)，kAnimFast；之后分页不重复动
Dialog / BottomSheet现 scale 0.92→1 保留，曲线换 spring（或 easeOutBack 轻回弹），模糊 8→4（降 GPU 压力）
面板开合（大纲/笔记 dock）宽度 spring 补间，可手势拖拽接管速度
路由维持 FadeThrough/SharedAxis；Android 接 PredictiveBack（框架自带，预测返回手势）
