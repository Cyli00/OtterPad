# 问 AI：图片引用、模型与过程展示

图片引用收进输入框，使用完整缩略图和右上角移除按钮。输入框及历史消息中的图片都直接打开现有 `figure_viewer`，从文献清单定位选中项并保留图集浏览；旧消息缺少清单时仍通过同一查看器打开单图。查看器里的“问 AI”将引用带回当前会话。

工具栏从左到右为模型选择、思考强度、联网搜索，保留流式输出开关。模型菜单按提供商分组，支持搜索、品牌图标和选中态，标注全局角色，选择不会修改全局配置。图标优先识别模型所属厂商，未知模型使用提供商标识或名称首字。参考 rikkahub 的品牌识别交互，SVG 直接来自 [LobeHub Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons)，内置 25 种品牌资源；MIT 许可随资源保存在 `assets/icons/lobe-icons-LICENSE`，无需运行时联网加载。

用户气泡按停靠栏实际宽度布局。引用默认展示两行，点击文字区展开或收起，只有独立的右侧定位按钮触发原文跳转；没有阅读器定位回调时隐藏该按钮。

发送按钮固定为桌面端 36×36、移动端 40×40 的圆角按钮，输入框从一行起步，最多增长至五行；空白输入时禁用发送，生成过程中同位置显示停止按钮。

定位使用划词时已有的段落锚点，随消息保存并在编辑、重试、重开时保留。WebView 按实际 DOM Range 滚动并短暂高亮，译文引用会显示对应原文；图片引用按图片文件名定位图表。旧消息没有锚点时，只接受唯一的渲染文本匹配。PDF 按段落身份找到页内区域。找不到时留在聊天页提示，不再按 Markdown 空行数量猜位置，也不会把定位所用的旧图片重新加入输入框。

Windows 的 `flutter_inappwebview_windows 0.6.0` 在 `sendScroll` 中将 Flutter 滚动量乘以 6 后注入 WebView2。阅读器对粗粒度纵向滚轮输入限制步长并逐帧缓动，反向输入立即取消余程；精细像素输入、缩放及内层滚动保留原生处理。阅读器资源 URL 与 HTML 指纹共用 `readerAssetVersion`，修改脚本时同步更新版本，避免一天的静态资源缓存继续提供旧逻辑。

快速模型的请求会剔除当前和历史图片，保留文献正文与图注，并在界面提示。其它模型按用户设置的图片输入能力发送图片；显式图片引用随所属消息重放，避免新图覆盖旧图。旧会话缺少新增字段时仍可正常加载。

思考和工具步骤统一命名为“ReAct 链”，参考 rikkahub 的折叠展示方式，接入服务商实际返回的事件，支持 OpenAI 摘要、Anthropic thinking、Gemini thought、兼容协议 reasoning_content，以及搜索和链接读取。状态区分进行中、完成、失败和停止，随会话保存；模型未提供思考内容时不生成虚构步骤。请求是否索取思考摘要，遵循模型能力配置。回答正文与用户气泡共用主题正文样式和紧凑行距。

消息列表按时间顺序从上往下布局，解决倒序列表把展开标题向上推的问题。新会话、发送消息及跟随中的流式更新滚到末尾；手动滚动或展开内容会暂停跟随。用户回到底部后恢复跟随。长回答测试检查展开动画中、展开完成及收起后的标题坐标，并验证查看链期间新增输出不会抢走位置。

联网搜索优先使用模型原生能力；兼容端回退到设置中选择的 Tavily、Exa 或 Brave。三家凭据独立存储，沿用安全存储和代理通路。接口依据：[Exa Search](https://exa.ai/docs/reference/search)、[Brave Web Search](https://api-dashboard.search.brave.com/api-reference/web/search/get)。没有使用真实凭据进行付费接口验证。

中文强调扩展直接生成 Markdown 节点，支持括号、引号与正文紧邻的加粗、斜体和删除线，保留代码、转义、链接与未完成流式片段。SSE 使用连续 UTF-8 解码，避免汉字跨网络分片时损坏。

每次问答在系统提示开头注入学习表达约束：围绕问题连续解释，每段一个主题，少量强调重点，列表最多两层，区分证据与推断，避免碎片化输出和无关扩展。用户明确指定的输出格式仍优先。

## 验证

```bash
flutter test --no-pub --concurrency=1 test/services/chat_flow_test.dart test/services/chat_markdown_test.dart test/pages/reader/chat_ui_test.dart test/widgets/ai_brand_icon_test.dart
```

覆盖请求体中的图片剔除、任意模型选择、三家搜索配置、Exa/Brave 请求与错误、四类思考协议、搜索回环、中文逐字节分片、停止后存档恢复、中文 Markdown 实际渲染，以及 280/420/800 宽度下的菜单与图片预览。测试使用临时库、模拟凭据与 HTTP adapter。

界面测试生成 `build/chat-ui-preview.png` 和 `build/chat-model-picker-preview.png`；可通过 `CHAT_UI_FONT` 指定本地中文字体、`CHAT_UI_FIGURE` 指定本地图片，用于人工检查。查看器复用测试覆盖无清单单图和有清单图集的初始页；引用交互测试分别检查展开与定位；图标测试加载全部内置 SVG 并验证深色模式。

覆盖粗粒度滚动、反向滚动、触控板与缩放放行、内层滚动、减少动态效果、文本/图表定位、重复引用消歧，以及真实 HTML 中“选中译文 → 获取锚点 → 显示并高亮原文”的往返。脚本复用本机已安装的 Playwright Chromium。
