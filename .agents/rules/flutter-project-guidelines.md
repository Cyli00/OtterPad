## UI Design Rules

Follow Material Design 3 (MD3) guidelines strictly

**Check Items:**
- ✓ Whether MD3 color system is used
- ✓ Whether spacing follows 4/8px grid
- ✓ Whether animation duration and easing curves comply with MD3
- ✓ Whether component accessibility requirements are met
- ✓ Whether dark/light theme adaptation is correct
